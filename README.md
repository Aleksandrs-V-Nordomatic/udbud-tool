# udbud-tool

The Danish reader for the tender radar. It will fetch a window of
[udbud.dk](https://udbud.dk) into the delivery shape every country tool in this family produces.

Latvia is `eis-tool`, Lithuania `epps-tool`, Estonia `rhr-tool`, Finland `hilma-tool`.

Being built. The first thing here is `egress-map`, which asks whether GitHub runner addresses get
the same answers from udbud.dk, TED and the document hosts that a workstation gets.
